# extension — Person C (Spec C — task C10)

**Delivers:** the same umbrella time on the laptop. The extension keeps its own list of distracting domains (on the laptop only) and is always metered: listed domains stay blocked unless the user spends minutes from the shared balance. Only the spend event syncs; the phone's weather never leaves the phone.

Pairs with the phone by a 6-digit code (5-minute expiry) through `cloud/ledger`.

Load it unpacked: `chrome://extensions` → Developer mode → Load unpacked → this folder.
