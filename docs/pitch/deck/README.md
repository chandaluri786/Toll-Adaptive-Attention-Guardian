# Pitch deck source

Source files for the Toll pitch deck (14 slides, with speaker notes in each slide's `aside`).

- `deck.json` lists the slide order and sections.
- `deck.css` holds the shared styles.
- `slides/*.html` are the slides, one file each.

The live deck is the Slides artifact: https://claude.ai/artifact/PtGEZm4i5BkXP9cR1RAsrA

Five slides (cover, earn, forecast twice, moment) show phone screenshots that are stored as artifact images (`/_blob/...`). Those paths do not resolve from this repo, so the screenshots will not show if you open the HTML here. Open the live deck, or re-export it, to see them.
